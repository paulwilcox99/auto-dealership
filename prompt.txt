Help me create a program that will simulate the business operation of a car dealership called Main Street Motors.  The dealership sells new and used cars and currently have a business development department (BD) that gets leads and contacts potential customers to get them to schedule a meeting, a Sales team that takes meetings with customers either from leads or from walk ins and tries to sell them a car and the finance team which handles the sale either as a cash deal or a loan payment.  The workflow is from new leads (or walk-ins) to sales, to finance.

The program simulates each day of business operation.  The user inputs a start date (if none specified use current) and how many days they want to simulate.  There are Simulation Databases set up at the beginning to hold the resource information (customers, employees, cars) that will be used in the simulation.  These are synthetic data created with Faker or LLM.   There is also a Results database that holds the results captured after each day.

The company consists of Company Databases that hold the information and track the flow of information as the simulation progresses.  These databases are meant to represent real systems in the car dealership.  The program has simulation functions that are used during the simulation to help generate synthetic data such as notes taken by employees at each stage.

The program has worker functions that represent the actions workers make to move data through the system and make decisions.

The program should be set up to initialize and then loop starting with the input start date for the number of dates specified to simulate, each loop increments the simulation date, each loop steps through each of the worker functions and performs the actions for that date.  Each worker function should be able to be disabled from the command line (so it can be replaced with an external script).  

The idea is for this simulation program to run in parallel with other programs that will synchronize to the current simulation date and will monitor the databases and act independently.  User should be able to step through each year manually (hitting return to progress to next year) or with a delay at the end of each year (default to 10 seconds)

Create the program with Python, use a virtual environment, use Faker and LLM where it makes sense, keep API keys in env file.
